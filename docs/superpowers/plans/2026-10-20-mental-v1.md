# mental v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local, keyboard-first mental-maths trainer with strategy-based hints (Free Play) and a 1-minute timed test with a results breakdown.

**Architecture:** A pure-Python engine (`src/mental/engine/`) generates seeded questions that carry their own answer, hints and worked steps, and summarises attempt records. A thin FastAPI app (`src/mental/web/app.py`) exposes `GET /api/questions` and `POST /api/summary` and serves one static page. Vanilla JS does input, checking, timing, streaks and builds attempt records.

**Tech Stack:** Python 3.14, uv, FastAPI, uvicorn, pytest, httpx2 (TestClient), vanilla HTML/CSS/JS, Press Start 2P font (OFL).

**Spec:** `docs/superpowers/specs/2026-10-20-mental-v1-design.md`

## Global Constraints

- Runtime deps: `fastapi`, `uvicorn` only. Dev deps: `pytest`, `httpx2` only.
- No Docker, JS frameworks, Redis, Postgres, cloud, auth, AI APIs, build step, persistence.
- `src/mental/engine/` never imports FastAPI or anything from `mental.web`.
- Every answer is an `int` with `|answer| ≤ 99_999`.
- Every step string is `"<sum> = <result>"` and arithmetically true; the last step's result is the answer.
- Each question has exactly 2 hints.
- Display numbers via `fmt()`: thousands commas and the real minus sign `−` (U+2212). Operators are `+ − × ÷`.
- Strategy IDs and the attempt record field names are fixed by the spec; do not rename them.
- Readable, ordinary code: functions, one dataclass, plain dicts. No classes beyond that.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Typing a negative answer** (`-465` or `−465`) is accepted; minus signs anywhere but the start are stripped. → manual check in Task 2, signed maths tested in Task 3.
2. **A hint that says nothing** (e.g. "50 = 50" when the number is already round) → generic test in Task 1 rejects any `X = X` hint.
3. **A test that ends with zero attempts** (nobody typed anything) must show results, not crash → `test_empty_attempts_do_not_crash` in Task 6.
4. **Bad input to the API** (unknown category, level 4, malformed or oversized attempt lists) returns 4xx, never 500 → tests in Task 2 and Task 6.
5. **Switching mode mid-test** stops the timer, so no stray results appear later → manual check in Task 5.

import pytest

from mental.engine.generate import CATEGORIES, make_question, make_questions
from mental.engine.strategies import STRATEGIES


def evaluate(expr):
    """Turn display maths ('1,234 × 2', '−5', '10% of 340') into Python and run it."""
    expr = expr.replace(",", "").replace("−", "-").replace("×", "*").replace("÷", "/")
    return eval(expr.replace("% of ", "/100*"))


CASES = [(sid, level) for sid, s in STRATEGIES.items() for level in s["difficulties"]]


@pytest.mark.parametrize("strategy_id, difficulty", CASES)
def test_strategy_maths_is_true(strategy_id, difficulty):
    make = STRATEGIES[strategy_id]["make"]
    for seed in range(300):
        text, answer, hints, steps = make(random.Random(seed), difficulty)
        assert type(answer) is int
        assert abs(answer) <= 99_999
        if "?" in text:
            left, right = text.split(" = ")
            assert evaluate(left) == evaluate(right.replace("?", str(answer))), text
        else:
            assert evaluate(text) == answer, text
        assert len(hints) == 2
        for h in hints:
            sides = h.split(" = ")
            assert len(sides) == 1 or sides[0] != sides[1], f"pointless hint: {h}"
        for step in steps:
            left, right = step.split(" = ")
            assert evaluate(left) == evaluate(right), f"{text}: {step}"
        assert evaluate(steps[-1].split(" = ")[1]) == answer, text


def test_strategy_categories_are_known():
    for s in STRATEGIES.values():

```python
"""Question generators.

Each strategy is a function (rng, difficulty) -> (text, answer, hints, steps).
It picks numbers that suit one mental trick and writes the explanation for them.
Every step must be a true sum written as "<sum> = <result>" (the tests check this).
"""


def fmt(n):
    """1234 -> '1,234' and -5 -> '−5' (a real minus sign, for display)."""
    return f"{n:,}".replace("-", "−")


def random_number(rng, digits):
    return rng.randint(10 ** (digits - 1), 10**digits - 1)


def place_parts(n):
    """2917 -> [2000, 900, 10, 7]"""
    s = str(n)
    return [int(d) * 10 ** (len(s) - 1 - i) for i, d in enumerate(s) if d != "0"]


def chunk_steps(start, parts, subtract=False):
    """Add (or take away) parts one at a time: ['4,382 + 2,000 = 6,382', ...]"""
    steps = []
    total = start
    for part in parts:
        new = total - part if subtract else total + part
        op = "−" if subtract else "+"
        steps.append(f"{fmt(total)} {op} {fmt(part)} = {fmt(new)}")
        total = new
    return steps


def basic_add(rng, difficulty):
    digits = difficulty + 1  # level 1: 2 digits, 2: 3 digits, 3: 4 digits
    a, b = random_number(rng, digits), random_number(rng, digits)
    b += 0 if b % 10 else 1  # a round b would make the hint pointless
    parts = place_parts(b)
    hints = [
        f"Add {fmt(b)} one place value at a time.",
        f"{fmt(b)} = {' + '.join(fmt(p) for p in parts)}",
    ]
    return f"{fmt(a)} + {fmt(b)}", a + b, hints, chunk_steps(a, parts)


def basic_subtract(rng, difficulty):
    digits = difficulty + 1
    b = random_number(rng, digits)
    b += 0 if b % 10 else 1  # a round b would make the hint pointless
    a = rng.randint(b, 10**digits - 1)
    parts = place_parts(b)
    hints = [
        f"Take {fmt(b)} away one place value at a time.",
        f"{fmt(b)} = {' + '.join(fmt(p) for p in parts)}",
    ]
    return f"{fmt(a)} − {fmt(b)}", a - b, hints, chunk_steps(a, parts, subtract=True)


def basic_multiply(rng, difficulty):
    if difficulty == 1:
        a, b = rng.randint(2, 9), rng.randint(2, 9)
        hints = [
            "This is a times-table fact.",
            f"{a} × {b - 1} = {a * (b - 1)}, then add one more {a}.",
        ]
        steps = [f"{a} × {b - 1} = {a * (b - 1)}", f"{a * (b - 1)} + {a} = {a * b}"]
        return f"{a} × {b}", a * b, hints, steps
    a = rng.choice([n for n in range(12, 100) if n % 10])
    b = rng.randint(3, 9)
    tens, units = a - a % 10, a % 10
    hints = [
        f"Split {a} into tens and units.",
        f"{a} × {b} = {tens} × {b} + {units} × {b}",
    ]
    steps = [
        f"{tens} × {b} = {tens * b}",
        f"{units} × {b} = {units * b}",
        f"{tens * b} + {units * b} = {a * b}",
    ]
    return f"{a} × {b}", a * b, hints, steps


def basic_divide(rng, difficulty):
    if difficulty == 1:
        b, q = rng.randint(2, 9), rng.randint(2, 9)
        a = b * q
        hints = ["Run the times table backwards.", f"{b} × ? = {a}"]
        steps = [f"{b} × {q} = {a}", f"{a} ÷ {b} = {q}"]
        return f"{a} ÷ {b}", q, hints, steps
    b = rng.randint(3, 9)
    q = rng.choice([n for n in range(12, 31) if n % 10])
    a = b * q
    tens = q - q % 10
    first, rest = b * tens, a - b * tens
    hints = [f"Split {a} into easy chunks of {b}.", f"{a} = {first} + {rest}"]
    steps = [
        f"{first} ÷ {b} = {tens}",
        f"{rest} ÷ {b} = {q - tens}",
        f"{tens} + {q - tens} = {q}",
    ]
    return f"{a} ÷ {b}", q, hints, steps


STRATEGIES = {
    "basic_add": {"category": "addition", "difficulties": [1, 2, 3], "make": basic_add},
    "basic_subtract": {"category": "subtraction", "difficulties": [1, 2, 3], "make": basic_subtract},
    "basic_multiply": {"category": "multiplication", "difficulties": [1, 2], "make": basic_multiply},
    "basic_divide": {"category": "division", "difficulties": [1, 2], "make": basic_divide},
}
```

- [ ] **Step 6: Write `src/mental/engine/generate.py`**

```python
import random

from mental.engine.question import Question
from mental.engine.strategies import STRATEGIES

CATEGORIES = ["addition", "subtraction", "multiplication", "division", "percentage", "relationship"]


def strategies_for(category, difficulty):
    return [sid for sid, s in STRATEGIES.items() if s["category"] == category and difficulty in s["difficulties"]]


def make_question(category, difficulty, seed):
    """The same (category, difficulty, seed) always gives the same question."""
    options = strategies_for(category, difficulty)
    if not options:
        raise ValueError(f"no {category} questions at level {difficulty}")
    rng = random.Random(seed)
    strategy = rng.choice(options)
    text, answer, hints, steps = STRATEGIES[strategy]["make"](rng, difficulty)
    return Question(
        id=f"{category}-{difficulty}-{seed}",
        seed=seed,
        text=text,
        answer=answer,
        category=category,
        strategy=strategy,
        difficulty=difficulty,
        hints=hints,
        steps=steps,
    )


def make_questions(categories, difficulty, count, seed=None):
    """count questions, each from a random one of categories that has questions at this level."""
    usable = [c for c in categories if strategies_for(c, difficulty)]
    if not usable:
        raise ValueError(f"no questions for {', '.join(categories)} at level {difficulty}")
    rng = random.Random(seed)
    return [make_question(rng.choice(usable), difficulty, rng.randrange(2**32)) for _ in range(count)]
```

from dataclasses import asdict
from pathlib import Path

from fastapi import FastAPI, HTTPException, Query
from fastapi.staticfiles import StaticFiles

from mental.engine.generate import CATEGORIES, make_questions

app = FastAPI(title="mental")


@app.get("/api/questions")
def get_questions(
    category: str = "mixed",  # "mixed", one category, or a comma-separated list
    difficulty: int = Query(1, ge=1, le=3),
    count: int = Query(20, ge=1, le=200),
):
    categories = CATEGORIES if category == "mixed" else category.split(",")
    unknown = [c for c in categories if c not in CATEGORIES]
    if unknown:
        raise HTTPException(400, f"unknown category: {', '.join(unknown)}")
    try:
        questions = make_questions(categories, difficulty, count)
    except ValueError as error:
        raise HTTPException(400, str(error))
    return [asdict(q) for q in questions]


# Mounted last so it doesn't swallow the /api routes.
app.mount("/", StaticFiles(directory=Path(__file__).parent / "static", html=True), name="static")

- [ ] **Step 6: Write `src/mental/web/static/app.js` (Free Play only)**

```js
// mental: the browser side. Shows questions, checks answers, times every attempt.
// Questions arrive from /api/questions already carrying their answer, hints and steps.

const CATEGORIES = ["mixed", "addition", "subtraction", "multiplication", "division", "percentage", "relationship"];
const KEYS = "Enter submit / next · H hint · Tab skip · C category · D level";

const $ = (id) => document.getElementById(id);
const input = $("answer");

const state = {
  mode: "free",
  category: "mixed",
  difficulty: 1,
  queue: [],          // fetched questions not shown yet
  current: null,      // question on screen
  attempt: null,      // attempt record for the current question
  shownAt: 0,
  solved: false,      // answered, waiting for Enter
  streak: 0,
  attempts: [],
};

async function fetchQuestions(count) {
  const params = new URLSearchParams({ category: state.category, difficulty: state.difficulty, count });
  const response = await fetch(`/api/questions?${params}`);
  if (!response.ok) throw new Error(`server said ${response.status}`);
  return response.json();
}

async function nextQuestion() {
  try {
    if (state.queue.length === 0) state.queue = await fetchQuestions(20);
  } catch (error) {
    setFeedback(`Could not load questions (${error.message})`, "wrong");
    return;
  }
  showQuestion(state.queue.shift());
}

function showQuestion(q) {
  state.current = q;
  state.solved = false;
  state.attempt = {
    question_id: q.id, seed: q.seed, text: q.text, category: q.category, strategy: q.strategy,
    difficulty: q.difficulty, answer: q.answer, given: "", correct: false, skipped: false,
    wrong_tries: [], hints_used: 0, time_ms: 0, mode: state.mode,
  };
  state.shownAt = performance.now();
  $("question").textContent = q.text;
  showLines([]);
  setFeedback("");
  input.value = "";
  input.focus();
}

// "−465" and "-465" both mean -465. Anything that isn't a whole number gives null.
function parseAnswer(text) {
  const clean = text.replace("−", "-");
  return /^-?\d+$/.test(clean) ? Number(clean) : null;
}

function finishAttempt(correct, skipped = false) {
  const a = state.attempt;
  a.given = input.value;
  a.correct = correct;
  a.skipped = skipped;
  a.time_ms = Math.round(performance.now() - state.shownAt);
  state.attempts.push(a);
  const clean = correct && a.wrong_tries.length === 0 && a.hints_used === 0;
  setStreak(clean ? state.streak + 1 : 0);
  $("score").textContent = `score ${state.attempts.filter((x) => x.correct).length}`;
}

function submit() {
  const value = parseAnswer(input.value);
  if (value === null) return;
  if (value === state.current.answer) {
    finishAttempt(true);
    state.solved = true;
    setFeedback("correct!  Enter for the next one", "right");
    showLines(state.current.steps);
    return;
  }
  state.attempt.wrong_tries.push(input.value);
  setFeedback("not quite", "wrong");
  input.select();
}

function hint() {
  if (!state.current || state.solved) return;
  const a = state.attempt;
  a.hints_used = Math.min(3, a.hints_used + 1);
  const lines = state.current.hints.slice(0, Math.min(a.hints_used, 2));
  if (a.hints_used === 3) lines.push(...state.current.steps);
  showLines(lines);
}

function skip() {
  if (!state.current || state.solved) return;
  finishAttempt(false, true);
  nextQuestion();
}

function onInput() {
  // allow digits and one leading minus only
  const cleaned = input.value.replace(/[^\d\-−]/g, "").replace(/(?!^)[-−]/g, "");
  if (cleaned !== input.value) input.value = cleaned;
}

function onEnter() {
  if (state.solved) return nextQuestion();
  if (state.current) submit();
}

// --- settings and display ---------------------------------------------------

function cycleCategory() {
  state.category = CATEGORIES[(CATEGORIES.indexOf(state.category) + 1) % CATEGORIES.length];
  settingsChanged();
}

function cycleDifficulty() {
  state.difficulty = (state.difficulty % 3) + 1;
  settingsChanged();
}

function settingsChanged() {
  state.queue = [];
  renderSettings();
  nextQuestion();
}

function renderSettings() {
  $("mode").textContent = "free play";
  $("category").textContent = state.category;
  $("difficulty").textContent = `level ${state.difficulty}`;
  $("timer").hidden = true;
  $("keys").textContent = KEYS;
}

function setStreak(n) {
  state.streak = n;
  $("streak").textContent = `streak ${n}`;
  document.body.dataset.heat = n >= 20 ? 3 : n >= 10 ? 2 : n >= 3 ? 1 : 0;
}

function setFeedback(text, kind = "") {
  const el = $("feedback");
  el.textContent = text;
  el.className = "";
  void el.offsetWidth;  // restart the flash animation even if the class is the same
  el.className = kind;
}

function showLines(lines) {
  $("help").replaceChildren(...lines.map((line) => {
    const li = document.createElement("li");
    li.textContent = line;
    return li;
  }));
}

// --- keyboard ----------------------------------------------------------------

document.addEventListener("keydown", (event) => {
  if (event.ctrlKey || event.metaKey || event.altKey) return;
  input.focus();
  const key = event.key.toLowerCase();
  if (key === "enter") onEnter();
  else if (key === "tab") skip();
  else if (key === "h") hint();
  else if (key === "c") cycleCategory();
  else if (key === "d") cycleDifficulty();
  else return;  // anything else (digits, minus, backspace) types normally
  event.preventDefault();
});

input.addEventListener("input", onInput);

renderSettings();
nextQuestion();
```

    if difficulty == 2:
        n, m = rng.choice([9, 11, 19, 21]), rng.randint(12, 49)

def double_halve(rng, difficulty):

```js
// mental: the browser side. Shows questions, checks answers, times every attempt.
// Questions arrive from /api/questions already carrying their answer, hints and steps.

const CATEGORIES = ["mixed", "addition", "subtraction", "multiplication", "division", "percentage", "relationship"];
const TEST_SECONDS = 60;
const KEYS = {
  free: "Enter submit / next · H hint · Tab skip · C category · D level · M test mode",
  test: "type the answer · Tab skip · C category · D level · M free play · Enter start",
};

const $ = (id) => document.getElementById(id);
const input = $("answer");

const state = {
  mode: "free",       // "free" | "test"
  category: "mixed",
  difficulty: 1,
  queue: [],          // fetched questions not shown yet
  seen: {},           // question id -> question, for the results screen
  current: null,      // question on screen
  attempt: null,      // attempt record for the current question
  shownAt: 0,
  solved: false,      // free play: answered, waiting for Enter
  streak: 0,
  attempts: [],
  testEndsAt: 0,      // 0 = no test running
  timer: null,
};

async function fetchQuestions(count) {
  const params = new URLSearchParams({ category: state.category, difficulty: state.difficulty, count });
  const response = await fetch(`/api/questions?${params}`);
  if (!response.ok) throw new Error(`server said ${response.status}`);
  return response.json();
}

async function nextQuestion() {
  try {
    if (state.queue.length === 0) state.queue = await fetchQuestions(state.mode === "test" ? 150 : 20);
  } catch (error) {
    setFeedback(`Could not load questions (${error.message})`, "wrong");
    return;
  }
  showQuestion(state.queue.shift());
}

function showQuestion(q) {
  state.current = q;
  state.seen[q.id] = q;
  state.solved = false;
  state.attempt = {
    question_id: q.id, seed: q.seed, text: q.text, category: q.category, strategy: q.strategy,
    difficulty: q.difficulty, answer: q.answer, given: "", correct: false, skipped: false,
    wrong_tries: [], hints_used: 0, time_ms: 0, mode: state.mode,
  };
  state.shownAt = performance.now();
  $("question").textContent = q.text;
  showLines([]);
  setFeedback("");
  input.value = "";
  input.focus();
}

// "−465" and "-465" both mean -465. Anything that isn't a whole number gives null.
function parseAnswer(text) {
  const clean = text.replace("−", "-");
  return /^-?\d+$/.test(clean) ? Number(clean) : null;
}

function finishAttempt(correct, skipped = false) {
  const a = state.attempt;
  a.given = input.value;
  a.correct = correct;
  a.skipped = skipped;
  a.time_ms = Math.round(performance.now() - state.shownAt);
  state.attempts.push(a);
  const clean = correct && a.wrong_tries.length === 0 && a.hints_used === 0;
  setStreak(clean ? state.streak + 1 : 0);
  $("score").textContent = `score ${state.attempts.filter((x) => x.correct).length}`;
}

function submit() {
  const value = parseAnswer(input.value);
  if (value === null) return;
  if (value === state.current.answer) {
    finishAttempt(true);
    state.solved = true;
    setFeedback("correct!  Enter for the next one", "right");
    showLines(state.current.steps);
    return;
  }
  state.attempt.wrong_tries.push(input.value);
  setFeedback("not quite", "wrong");
  input.select();
}

function hint() {
  if (!state.current || state.solved) return;
  const a = state.attempt;
  a.hints_used = Math.min(3, a.hints_used + 1);
  const lines = state.current.hints.slice(0, Math.min(a.hints_used, 2));
  if (a.hints_used === 3) lines.push(...state.current.steps);
  showLines(lines);
}

function skip() {
  if (!state.current || state.solved) return;
  if (state.mode === "test" && !state.testEndsAt) return;
  finishAttempt(false, true);
  nextQuestion();
}

function onInput() {
  // allow digits and one leading minus only
  const cleaned = input.value.replace(/[^\d\-−]/g, "").replace(/(?!^)[-−]/g, "");
  if (cleaned !== input.value) input.value = cleaned;
  // test mode accepts the right answer as soon as it is typed
  if (state.mode === "test" && state.testEndsAt && state.current &&
      parseAnswer(input.value) === state.current.answer) {
    finishAttempt(true);
    nextQuestion();
  }
}

function onEnter() {
  if (state.mode === "test" && !state.testEndsAt) return startTest();
  if (state.mode === "free" && state.solved) return nextQuestion();
  if (state.current) submit();
}

// --- test mode -------------------------------------------------------------

function showTestIntro() {
  state.current = null;
  $("question").textContent = "1 minute. Enter to start";
  $("timer").textContent = `${TEST_SECONDS}s`;
  input.value = "";
  showLines([]);
  setFeedback("");
}

async function startTest() {
  state.testEndsAt = Infinity;  // running, real end time set once questions arrive
  state.current = null;
  state.queue = [];
  state.attempts = [];
  state.seen = {};
  setStreak(0);
  $("score").textContent = "score 0";
  $("results").hidden = true;
  await nextQuestion();
  if (!state.current) return stopTest();
  state.testEndsAt = performance.now() + TEST_SECONDS * 1000;
  state.timer = setInterval(tick, 100);
}

function tick() {
  const left = state.testEndsAt - performance.now();
  $("timer").textContent = `${Math.max(0, Math.ceil(left / 1000))}s`;
  if (left <= 0) endTest();
}

function stopTest() {
  clearInterval(state.timer);
  state.testEndsAt = 0;
}

function endTest() {
  stopTest();
  state.current = null;  // the unfinished question is not recorded
  input.value = "";
  $("question").textContent = `time!  score ${state.attempts.filter((a) => a.correct).length}`;
}

// --- settings and display ---------------------------------------------------

function switchMode() {
  stopTest();
  state.mode = state.mode === "free" ? "test" : "free";
  state.queue = [];
  state.attempts = [];
  setStreak(0);
  $("score").textContent = "score 0";
  $("results").hidden = true;
  renderSettings();
  if (state.mode === "free") nextQuestion();
  else showTestIntro();
}

function cycleCategory() {
  state.category = CATEGORIES[(CATEGORIES.indexOf(state.category) + 1) % CATEGORIES.length];
  settingsChanged();
}

function cycleDifficulty() {
  state.difficulty = (state.difficulty % 3) + 1;
  settingsChanged();
}

function settingsChanged() {
  state.queue = [];
  renderSettings();
  if (state.mode === "free") nextQuestion();
}

function renderSettings() {
  $("mode").textContent = state.mode === "free" ? "free play" : "test yourself";
  $("category").textContent = state.category;
  $("difficulty").textContent = `level ${state.difficulty}`;
  $("timer").hidden = state.mode === "free";
  $("keys").textContent = KEYS[state.mode];
}

function setStreak(n) {
  state.streak = n;
  $("streak").textContent = `streak ${n}`;
  document.body.dataset.heat = n >= 20 ? 3 : n >= 10 ? 2 : n >= 3 ? 1 : 0;
}

function setFeedback(text, kind = "") {
  const el = $("feedback");
  el.textContent = text;
  el.className = "";
  void el.offsetWidth;  // restart the flash animation even if the class is the same
  el.className = kind;
}

function showLines(lines) {
  $("help").replaceChildren(...lines.map((line) => {
    const li = document.createElement("li");
    li.textContent = line;
    return li;
  }));
}

// --- keyboard ----------------------------------------------------------------

document.addEventListener("keydown", (event) => {
  if (event.ctrlKey || event.metaKey || event.altKey) return;
  input.focus();
  const key = event.key.toLowerCase();
  const running = state.testEndsAt !== 0;
  if (key === "enter") onEnter();
  else if (key === "tab") skip();
  else if (key === "h" && state.mode === "free") hint();
  else if (key === "m") switchMode();
  else if (key === "c" && !running) cycleCategory();
  else if (key === "d" && !running) cycleDifficulty();
  else return;  // anything else (digits, minus, backspace) types normally
  event.preventDefault();
});

input.addEventListener("input", onInput);

renderSettings();
nextQuestion();
```

```python
"""Turn a list of attempt records into accuracy and speed numbers.

"accuracy" counts clean answers: correct on the first try with no hints.
"avg_time_ms" is over solved questions only, so skips don't drag it down.
"""


def stats(attempts):
    solved = [a for a in attempts if a["correct"]]
    clean = [a for a in solved if not a["wrong_tries"] and a["hints_used"] == 0]
    return {
        "count": len(attempts),
        "score": len(solved),
        "skipped": sum(1 for a in attempts if a["skipped"]),
        "accuracy": len(clean) / len(attempts) if attempts else 0.0,
        "avg_time_ms": round(sum(a["time_ms"] for a in solved) / len(solved)) if solved else 0,
    }


def group_stats(attempts, key):
    groups = {}
    for a in attempts:
        groups.setdefault(a[key], []).append(a)
    return {name: stats(group) for name, group in groups.items()}


def summarise(attempts):
    slowest = sorted(attempts, key=lambda a: a["time_ms"], reverse=True)[:5]
    return {
        "overall": stats(attempts),
        "by_category": group_stats(attempts, "category"),
        "by_strategy": group_stats(attempts, "strategy"),
        "slowest": [a["question_id"] for a in slowest],
    }
```

async function endTest() {
  stopTest();
  state.current = null;  // the unfinished question is not recorded
  $("question").textContent = "time!";
  input.value = "";
  const response = await fetch("/api/summary", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(state.attempts),
  });
  if (!response.ok) return setFeedback(`Could not load results (server said ${response.status})`, "wrong");
  showResults(await response.json());
}

const percent = (x) => `${Math.round(x * 100)}%`;
const seconds = (ms) => `${(ms / 1000).toFixed(1)}s`;

function showResults(summary) {
  const o = summary.overall;
  const rows = Object.entries(summary.by_category)
    .map(([name, s]) => `<tr><td>${name}</td><td>${s.score}/${s.count}</td><td>${percent(s.accuracy)}</td><td>${seconds(s.avg_time_ms)}</td></tr>`)
    .join("");
  const slowest = summary.slowest
    .map((id) => state.seen[id])
    .map((q) => `<li>${q.text}<br><small>${q.steps.join("  →  ")}</small></li>`)
    .join("");
  $("results").innerHTML = `
    <h2>score ${o.score}</h2>
    <p>accuracy ${percent(o.accuracy)} · avg ${seconds(o.avg_time_ms)} · skipped ${o.skipped}</p>
    <table><tr><th>category</th><th>solved</th><th>clean</th><th>avg</th></tr>${rows}</table>
    <h3>slowest: learn these</h3><ol>${slowest}</ol>
    <p>Enter to go again</p>`;
  $("results").hidden = false;
}
