# mental v1.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the app remember you: local players, every finished test and practice session saved to SQLite with its attempts, the server re-checking every saved answer, a personal best, My stats and a leaderboard; rename Free Play to Practice and give it Quit plus a summary.

**Architecture:** Same shape as v1.1. The engine gains `check.py`, which rebuilds a question from its id and decides `correct` itself. A new `mental/store.py` owns the SQLite file: fixed SQL strings with `?` placeholders only. `app.py` gets player, round, stats and leaderboard routes that open one connection per request. The page gets a player screen, Practice Quit and summary, saving through `/api/rounds`, and My stats and Leaderboard screens.

**Tech Stack:** Python 3.14, uv, FastAPI, stdlib `sqlite3`, pytest, vanilla HTML/CSS/JS. Browser check: Playwright via `uv run --with playwright` (not a project dependency).

**Spec:** `docs/superpowers/specs/2026-10-21-mental-v1.2-design.md` (builds on the v1 and v1.1 specs)

## Global Constraints

- Runtime deps stay `fastapi`, `uvicorn`; dev deps stay `pytest`, `httpx2`. SQLite is the standard library's `sqlite3`. Playwright is never added to `pyproject.toml`.
- `src/mental/engine/` never imports FastAPI, `mental.web` or `mental.store`.
- **Every SQL statement is a fixed string with `?` placeholders; values are passed separately. No f-string, `%`, `.format` or `+` ever builds SQL.**
- **Anything a person typed (a player name) goes on the page with `textContent`, never `innerHTML`.**
- Player names: 1–16 characters of letters, digits, spaces, `_`, `.`, `-`, no space at either end, unique ignoring case. One regex, the same on both sides: `^[A-Za-z0-9_.-]([A-Za-z0-9 _.-]{0,14}[A-Za-z0-9_.-])?$`.
- The database is `$MENTAL_DB` if set, else `~/.mental/mental.db`. Tests and the browser check never touch the real one.
- The attempt record `mode` is `"practice"` or `"test"` (was `"free"`); strategy IDs never change.
- Display minus is ASCII `-`; the answer box accepts `-` and `−`.
- No visual design work beyond plain styling for the new screens.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A practice session saved twice or lost.** Esc then Enter on the summary, quitting while a refill is in flight, or quitting and then closing the tab must save the session exactly once. Reloading mid-practice must still save what was finished. → browser check "the session was saved once", "a refill landing after quitting shows nothing", "reloading mid-practice still saves what was finished" (Task 4).
2. **A browser lying about an answer.** `correct: true` on a wrong answer, a changed question text or a made-up question id must not count. The server's verdict wins, or the request gets 400. → `tests/test_check.py` (Task 1), `test_the_server_decides_what_is_correct` and `test_attempt_that_does_not_match_its_question_is_400` (Task 3).
3. **Names with SQL or HTML in them.** A name with quotes is stored and returned unchanged. A name with `<`, `;` or quotes is refused by the API. Any name, whatever it contains, is shown as text and never run. → `test_sql_in_a_name_is_stored_as_plain_text` (Task 2), `test_bad_names_are_422` (Task 3), browser checks "a name is shown as text, never run as HTML" (Tasks 4 and 5).
4. **Remembered player gone, or server down at load.** The page must ask again, or say so and offer Retry. It must never leave a blank page. → browser checks "a remembered player that no longer exists gets asked again" and "server down at load: says so and offers Retry" (Task 4).
5. **Tests writing into the real database.** An autouse fixture points `MENTAL_DB` at a temp file for every pytest test (Task 2). The browser check's instructions start its server on a throwaway database (Task 4).

```python
"""Attempt records built the way app.js builds them, for tests."""
from mental.engine.generate import make_question


def record(question, given, **changes):
    """One attempt record for question with `given` typed; `changes` overrides any field."""
    attempt = {
        "question_id": question.id, "seed": question.seed, "text": question.text,
        "category": question.category, "strategy": question.strategy, "difficulty": question.difficulty,
        "answer": question.answer, "given": given, "correct": False, "skipped": False,
        "wrong_tries": [], "gave_up": False, "time_ms": 1500, "mode": "test",
    }
    return {**attempt, **changes}


def records(right, wrong=0):
    """Records for different addition questions: `right` answered correctly, then `wrong` skipped."""
    out = []
    for seed in range(right + wrong):
        q = make_question("addition", 1, seed)
        if seed < right:
            out.append(record(q, str(q.answer), correct=True, time_ms=1000 + seed))
        else:
            out.append(record(q, "", skipped=True, time_ms=1000 + seed))
    return out
```

```python
"""Re-check attempt records that come back from the browser before they are saved.

The browser could send anything, so nothing it says about a question, or about being right,
counts: each question is rebuilt from its id and `correct` is worked out from what was typed.
"""
import re

from mental.engine.generate import make_question


def question_from_id(question_id):
    """'division-2-77' -> the very Question make_question gave out. ValueError if it can't be."""
    try:
        category, difficulty, seed = question_id.rsplit("-", 2)
        question = make_question(category, int(difficulty), int(seed))
    except ValueError:
        raise ValueError(f"not a question id: {question_id!r}") from None
    if question.id != question_id:  # "1_000" or " 5" parse as numbers but are not how ids are written
        raise ValueError(f"not a question id: {question_id!r}")
    return question


def parse_answer(text):
    """As app.js's parseAnswer: '-465' and '−465' are -465; anything else is None."""
    clean = text.replace("−", "-")
    return int(clean) if re.fullmatch(r"-?[0-9]+", clean) else None


def checked(attempt):
    """A copy of an attempt record whose question fields and `correct` come from the server.

    ValueError if the id isn't a real question or the text doesn't match it.
    """
    question = question_from_id(attempt["question_id"])
    if attempt["text"] != question.text:
        raise ValueError(f"{attempt['question_id']} is {question.text!r}, not {attempt['text']!r}")
    answered = not attempt["skipped"] and not attempt["gave_up"]
    return {
        **attempt,
        "seed": question.seed,
        "category": question.category,
        "strategy": question.strategy,
        "difficulty": question.difficulty,
        "answer": question.answer,
        "correct": answered and parse_answer(attempt["given"]) == question.answer,
    }
```

```python
"""Saved players, rounds and attempts, in one SQLite file.

Every statement is a fixed string with ? placeholders, and the values are passed separately, so
nothing a player types can change what a query does. Never build SQL with f-strings, %, .format or +.
"""
import json
import os
import sqlite3
from datetime import UTC, datetime
from pathlib import Path

# A round is one finished test or practice session. PRAGMA user_version is the schema version,
# so a later version can see what it is upgrading from.
SCHEMA = """
CREATE TABLE IF NOT EXISTS players (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL UNIQUE COLLATE NOCASE,
    created_at TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS rounds (
    id INTEGER PRIMARY KEY,
    player_id INTEGER NOT NULL REFERENCES players(id),
    mode TEXT NOT NULL CHECK (mode IN ('practice', 'test')),
    score INTEGER NOT NULL,
    finished_at TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS attempts (
    id INTEGER PRIMARY KEY,
    round_id INTEGER NOT NULL REFERENCES rounds(id),
    question_id TEXT NOT NULL,
    seed INTEGER NOT NULL,
    text TEXT NOT NULL,
    category TEXT NOT NULL,
    strategy TEXT NOT NULL,
    difficulty INTEGER NOT NULL,
    answer INTEGER NOT NULL,
    given TEXT NOT NULL,
    correct INTEGER NOT NULL,
    skipped INTEGER NOT NULL,
    gave_up INTEGER NOT NULL,
    wrong_tries TEXT NOT NULL,  -- JSON list of strings
    time_ms INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS rounds_by_player ON rounds (player_id, mode);
CREATE INDEX IF NOT EXISTS attempts_by_round ON attempts (round_id);
PRAGMA user_version = 1;
"""


class NameTaken(Exception):
    pass


def db_path():
    return Path(os.environ.get("MENTAL_DB") or Path.home() / ".mental" / "mental.db")


def connect(path=None):
    path = Path(path or db_path())
    path.parent.mkdir(parents=True, exist_ok=True)
    # FastAPI may open the connection on one worker thread and use it on another (never at once)
    conn = sqlite3.connect(path, check_same_thread=False)
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA foreign_keys = ON")
    if conn.execute("PRAGMA user_version").fetchone()[0] == 0:
        conn.executescript(SCHEMA)
    return conn


def now():
    return datetime.now(UTC).isoformat(timespec="seconds")


def add_player(conn, name):
    try:
        with conn:
            cursor = conn.execute("INSERT INTO players (name, created_at) VALUES (?, ?)", (name, now()))
    except sqlite3.IntegrityError:
        raise NameTaken(name) from None
    return {"id": cursor.lastrowid, "name": name}


def players(conn):
    return [dict(row) for row in conn.execute("SELECT id, name FROM players ORDER BY name COLLATE NOCASE")]


def player_exists(conn, player_id):
    return conn.execute("SELECT 1 FROM players WHERE id = ?", (player_id,)).fetchone() is not None


def save_round(conn, player_id, mode, attempts):
    """Store a finished round and its attempts (already checked). Returns the round id."""
    score = sum(1 for a in attempts if a["correct"])
    with conn:
        cursor = conn.execute(
            "INSERT INTO rounds (player_id, mode, score, finished_at) VALUES (?, ?, ?, ?)",
            (player_id, mode, score, now()),
        )
        conn.executemany(
            """INSERT INTO attempts (round_id, question_id, seed, text, category, strategy, difficulty,
                   answer, given, correct, skipped, gave_up, wrong_tries, time_ms)
               VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)""",
            [
                (cursor.lastrowid, a["question_id"], a["seed"], a["text"], a["category"], a["strategy"],
                 a["difficulty"], a["answer"], a["given"], a["correct"], a["skipped"], a["gave_up"],
                 json.dumps(a["wrong_tries"]), a["time_ms"])
                for a in attempts
            ],
        )
    return cursor.lastrowid


def best_score(conn, player_id):
    """Best test score, or None before the first test."""
    return conn.execute(
        "SELECT MAX(score) FROM rounds WHERE player_id = ? AND mode = 'test'", (player_id,)
    ).fetchone()[0]


def history(conn, player_id):
    """How many tests, the best score and the last 10 scores, newest first."""
    count, best = conn.execute(
        "SELECT COUNT(*), MAX(score) FROM rounds WHERE player_id = ? AND mode = 'test'", (player_id,)
    ).fetchone()
    recent = conn.execute(
        "SELECT score, finished_at AS at FROM rounds WHERE player_id = ? AND mode = 'test' ORDER BY id DESC LIMIT 10",
        (player_id,),
    )
    return {"count": count, "best": best, "recent": [dict(row) for row in recent]}


def player_attempts(conn, player_id):
    """Every saved attempt of one player, shaped like the records summary.py reads."""
    rows = conn.execute(
        """SELECT a.*, r.mode FROM attempts a JOIN rounds r ON r.id = a.round_id
           WHERE r.player_id = ? ORDER BY a.id""",
        (player_id,),
    )
    return [
        {**dict(row), "correct": bool(row["correct"]), "skipped": bool(row["skipped"]),
         "gave_up": bool(row["gave_up"]), "wrong_tries": json.loads(row["wrong_tries"])}
        for row in rows
    ]


def leaderboard(conn):
    """Top 10 players by best test score (ties alphabetical). Players with no test are left out."""
    rows = conn.execute(
        """SELECT p.id, p.name, MAX(r.score) AS best FROM rounds r JOIN players p ON p.id = r.player_id
           WHERE r.mode = 'test' GROUP BY p.id ORDER BY best DESC, p.name COLLATE NOCASE LIMIT 10"""
    )
    return [dict(row) for row in rows]
```

  - `GET /api/players` → `[{id, name}]`.
  - `POST /api/players {name}` → `{id, name}`, or 409 / 422.
  - `POST /api/rounds {player_id, mode: "practice"|"test", attempts}` → `{summary, best}`, where `best` is `{previous: int|null, best: int}` for a test and `null` for practice. Errors: 404 unknown player, 400 bad attempt, 422 invalid body.

  - `GET /api/leaderboard` → `[{id, name, best}]`.
  - Every response carries `Cache-Control: no-cache`.
  - `POST /api/summary` stays until Task 4 (the v1.1 page still calls it). Its `Attempt` model now takes `mode: "practice"|"test"`.

```js
// Arrow keys move the highlight the way they point; Enter or Space picks the item.
function onMenuKey(event) {

// The menu item nearest to `from` in direction [dx, dy]. An item counts only if it lies more in
// that direction than off to the side. Null at the edge, so the highlight stays put.
function nearestItem(from, [dx, dy]) {
  const items = [...document.querySelectorAll(".screen:not([hidden]) [data-nav]")];
  if (!items.includes(from)) return items[0];
  const box = (el) => (el.closest("label") || el).getBoundingClientRect();  // a tickbox's label is what you see
  const gap = (v, low, high) => Math.max(low - v, 0, v - high);  // 0 when v is within [low, high]
  const here = box(from);
  const x = here.left + here.width / 2;
  const y = here.top + here.height / 2;
  let best = null;
  let bestScore = Infinity;
  for (const item of items) {
    const b = box(item);
    const ahead = (b.left + b.width / 2 - x) * dx + (b.top + b.height / 2 - y) * dy;
    const aside = dx ? gap(y, b.top, b.bottom) : gap(x, b.left, b.right);
    const score = ahead + aside * 3;
    if (ahead > 1 && aside < ahead && score < bestScore) {
      best = item;
      bestScore = score;
    }
  }
  return best;
}

  state.countingDown = false;
  $("game").classList.remove("counting");
  if (questions instanceof Error) return showLoadError(questions);
  state.queue = questions;
  showQuestion(state.queue.shift());
  if (state.mode === "test") {
    state.testEndsAt = performance.now() + TEST_SECONDS * 1000;
    state.timer = setInterval(tick, 100);
  }
}

// --- questions -------------------------------------------------------------

async function fetchQuestions(count) {
  const params = new URLSearchParams({ category: state.category, difficulty: state.difficulty, count });
  return getJSON(`/api/questions?${params}`);
}

async function nextQuestion() {
  if (state.queue.length === 0) {
    if (state.loading) return;  // already fetching
    const session = state.session;
    state.loading = true;
    state.current = null;  // nothing on screen to answer or skip while loading
    state.solved = false;
    $("question").textContent = "";
    showSteps([]);
    setFeedback("");
    showAnswerBox(false);
    $("retry").hidden = true;
    try {
      const questions = await fetchQuestions(QUESTIONS_PER_FETCH[state.mode]);
      if (session !== state.session) return;  // went back to the menu while loading
      state.queue = questions;
    } catch (error) {
      if (session === state.session) showLoadError(error);
      return;
    } finally {
      if (session === state.session) state.loading = false;
    }
  }
  showQuestion(state.queue.shift());
}

// Shown when questions fail to load. The Retry button lets the mouse do what Enter does.
function showLoadError(error) {
  $("question").textContent = "";
  setFeedback(`Could not load questions (${error.message}). Enter to retry.`, "wrong");
  $("retry").hidden = false;
}

function showQuestion(q) {
  state.current = q;
  $("retry").hidden = true;
  state.seen[q.id] = q;
  state.solved = false;
  state.attempt = {
    question_id: q.id, seed: q.seed, text: q.text, category: q.category, strategy: q.strategy,
    difficulty: q.difficulty, answer: q.answer, given: "", correct: false, skipped: false,
    wrong_tries: [], gave_up: false, time_ms: 0, mode: state.mode,
  };
  state.shownAt = performance.now();  // practice times every question too, without showing it
  $("question").textContent = q.text;
  showSteps([]);
  setFeedback("");
  renderButtons();
  showAnswerBox(true);
  input.value = "";
  input.focus();
}

// "−465" and "-465" both mean -465. Anything that isn't a whole number gives null.
function parseAnswer(text) {
  const clean = text.replace("−", "-");
  return /^-?\d+$/.test(clean) ? Number(clean) : null;
}

function finishAttempt(correct, skipped = false) {
  const a = state.attempt;
  a.given = input.value;
  a.correct = correct;
  a.skipped = skipped;
  a.time_ms = Math.round(performance.now() - state.shownAt);
  state.attempts.push(a);
  setStreak(correct && a.wrong_tries.length === 0 ? state.streak + 1 : 0);
  $("score").textContent = `score ${state.attempts.filter((x) => x.correct).length}`;
}

function submit() {
  const value = parseAnswer(input.value);
  if (value === null) return;
  if (value === state.current.answer) {
    finishAttempt(true);
    state.solved = true;
    setFeedback("correct!  Enter for the next one", "right");
    showSteps(state.current.steps);
    renderButtons();
    return;
  }
  if (input.value === state.attempt.wrong_tries.at(-1)) return;  // same wrong value again
  state.attempt.wrong_tries.push(input.value);
  setFeedback(wrongLine(value, state.current.answer), "wrong");
  input.select();
}

// What to say after a wrong answer depends on how far off it was.
const WRONG_LINES = {
  close: ["almost!", "so close", "nearly there", "off by a hair"],
  off: ["not quite", "nope, try again", "not it", "try again"],
  way: ["are you even trying?", "jesus.", "that's not even close", "...what?", "bold guess"],
};
let lastWrongLine = "";

function wrongLine(given, answer) {
  const diff = Math.abs(given - answer);
  const gap = diff / Math.max(Math.abs(answer), 10);  // how far off, as a share of the answer
  const wrongSign = given * answer < 0;
  const tier = wrongSign || gap > 0.5 ? "way" : diff <= 1 || gap <= 0.05 ? "close" : "off";
  const options = WRONG_LINES[tier].filter((line) => line !== lastWrongLine);
  lastWrongLine = options[Math.floor(Math.random() * options.length)];
  return lastWrongLine;
}

function giveUp() {
  if (!state.current || state.solved) return;
  state.attempt.gave_up = true;
  finishAttempt(false);
  state.solved = true;
  const answer = state.current.steps.at(-1).split(" = ")[1];  // already formatted, e.g. "1,480"
  setFeedback(`the answer is ${answer}.  Enter for the next one`, "wrong");
  showSteps(state.current.steps);
  renderButtons();
}

function skip() {
  if (!state.current || !state.testEndsAt) return;  // only during a running test
  finishAttempt(false, true);
  nextQuestion();
}

// Quit (button or Esc): the question on screen is not recorded; the rest is saved and summed up.
function quitPractice() {
  if (state.finished) return;
  if (state.attempts.length === 0) return showHome();
  endRound();
}

function onInput() {
  // allow one leading minus and up to 5 digits (no answer is longer)
  const cleaned = input.value.replace(/[^\d\-−]/g, "").replace(/(?!^)[-−]/g, "").replace(/^([-−]?\d{0,5}).*$/, "$1");
  if (cleaned !== input.value) input.value = cleaned;
  // test mode accepts the right answer as soon as it is typed
  if (state.mode === "test" && state.testEndsAt && state.current &&
      parseAnswer(input.value) === state.current.answer) {
    finishAttempt(true);
    nextQuestion();
  }
}

function onEnter() {
  if (state.countingDown) return;
  if (state.finished || (state.mode === "test" && !state.testEndsAt)) {
    // between rounds, or the test's first load failed. A late Enter from the last answer must
    // not skip straight past the results.
    if (performance.now() - state.endedAt > 1000) startRound();
    return;
  }
  if (state.mode === "test") return state.current ? recordWrongTry() : nextQuestion();  // no question: retry the load
  if (!state.current || state.solved) return nextQuestion();  // also retries a failed load
  submit();
}

// Esc quits practice (with its summary); anywhere else in a game it goes home.
function onEscape() {
  if (state.mode === "practice" && !state.finished && !state.countingDown) quitPractice();
  else showHome();
}

// Test mode gives no feedback on a wrong answer (that would be a hint), but keeps it for the stats.
function recordWrongTry() {
  const value = parseAnswer(input.value);
  if (!state.current || value === null || value === state.current.answer) return;
  if (input.value !== state.attempt.wrong_tries.at(-1)) state.attempt.wrong_tries.push(input.value);
}

// --- the end of a round --------------------------------------------------------

const clock = (seconds) => `${Math.floor(seconds / 60)}:${String(seconds % 60).padStart(2, "0")}`;

function tick() {
  const left = state.testEndsAt - performance.now();
  $("timer").textContent = clock(Math.max(0, Math.ceil(left / 1000)));
  if (left <= 0) endRound();
}

function stopTest() {
  clearInterval(state.timer);
  state.testEndsAt = 0;
}

// The test's buzzer or quitting practice: save the round, then show what the server made of it.
async function endRound() {
  stopTest();
  state.session++;  // a question refill still in flight must not show up over the results
  const session = state.session;
  state.finished = true;
  state.current = null;  // the unfinished question is not recorded
  state.endedAt = performance.now();
  const attempts = state.attempts;
  state.attempts = [];  // handed over below, so closing the tab can't send them a second time
  $("question").textContent = state.mode === "test" ? "time!" : "done!";
  input.value = "";
  showSteps([]);
  setFeedback("");
  showAnswerBox(false);
  $("retry").hidden = true;
  let saved;
  try {
    const response = await fetch("/api/rounds", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ player_id: state.player.id, mode: state.mode, attempts }),
    });
    if (!response.ok) throw new Error(`server said ${response.status}`);
    saved = await response.json();
  } catch (error) {
    if (session === state.session) setFeedback(`Could not save results (${error.message})`, "wrong");
    return;
  }
  if (session !== state.session) return;  // moved on while it saved
  showResults(saved.summary, saved.best);
}

// Closing or reloading the tab mid-practice still saves the questions already finished.
addEventListener("pagehide", () => {

  navigator.sendBeacon("/api/rounds", new Blob([body], { type: "application/json" }));

});

const percent = (x) => `${Math.round(x * 100)}%`;
const seconds = (ms) => `${(ms / 1000).toFixed(1)}s`;
const plural = (n, word) => `${n} ${word}${n === 1 ? "" : "s"}`;

// Only numbers and the server's own question text, steps and topic names go into this HTML.
function showResults(summary, best) {
  const o = summary.overall;
  const rows = Object.entries(summary.by_category)
    .map(([name, s]) => `<tr><td>${name}</td><td>${s.score}/${s.count}</td><td>${percent(s.accuracy)}</td><td>${seconds(s.avg_time_ms)}</td></tr>`)
    .join("");
  const slowest = summary.slowest
    .map((id) => state.seen[id])
    .map((q) => `<li>${q.text}<br><small>${q.steps.join("  →  ")}</small></li>`)
    .join("");
  const top = state.mode === "test"

       <p class="best">${bestLine(o.score, best)}</p>

    : `<h2>practice done</h2>
       <p>${plural(o.count, "question")} · ${o.score} solved · first try ${percent(o.accuracy)} · gave up ${o.gave_up} · avg ${seconds(o.avg_time_ms)}</p>`;
  $("results").innerHTML = `

}

// best = {previous, best} from the server; previous is null before the first test.
function bestLine(score, best) {
  if (best.previous === null) return `first test · best ${best.best}`;
  if (score > best.previous) return `new best! (was ${best.previous})`;
  return `best ${best.best}`;
}
```

```js
// --- my stats and the leaderboard --------------------------------------------

async function showMyStats() {
  showScreen("my-stats");
  document.querySelector("#my-stats [data-back]").focus();
  $("my-stats-body").textContent = "loading...";
  let stats;
  try {
    stats = await getJSON(`/api/players/${state.player.id}/stats`);
  } catch (error) {
    $("my-stats-body").textContent = `Could not load your stats (${error.message}).`;
    return;
  }
  if ($("my-stats").hidden) return;  // left the screen while it loaded
  const t = stats.tests;
  const recent = t.recent
    .map((r) => `<li>${r.score} <small>${new Date(r.at).toLocaleDateString()}</small></li>`)
    .join("");
  const rows = Object.entries(stats.by_category)
    .map(([name, s]) => `<tr><td>${name}</td><td>${s.count}</td><td>${s.score}</td><td>${percent(s.accuracy)}</td><td>${seconds(s.avg_time_ms)}</td></tr>`)
    .join("");
  // only numbers, dates and the server's topic names go into this HTML: nothing anyone typed
  $("my-stats-body").innerHTML = `
    <h3>tests</h3>
    <p>${t.count ? `${t.count} taken · best ${t.best}` : "no tests yet"}</p>
    ${recent ? `<ol>${recent}</ol>` : ""}
    <h3>by topic</h3>
    ${rows ? `<table><tr><th>topic</th><th>done</th><th>solved</th><th>first try</th><th>avg</th></tr>${rows}</table>` : "<p>nothing played yet</p>"}`;
}

async function showLeaderboard() {
  showScreen("leaderboard");
  document.querySelector("#leaderboard [data-back]").focus();
  const list = $("leaderboard-list");
  list.replaceChildren(listItem("loading...", "note"));
  let rows;
  try {
    rows = await getJSON("/api/leaderboard");
  } catch (error) {
    list.replaceChildren(listItem(`Could not load the leaderboard (${error.message}).`, "note"));
    return;
  }
  if ($("leaderboard").hidden) return;
  if (rows.length === 0) return list.replaceChildren(listItem("no tests yet", "note"));
  // names are typed by people: listItem puts them in as text
  list.replaceChildren(...rows.map((r) => listItem(`${r.name} · ${r.best}`, r.id === state.player.id ? "me" : "")));
}

function listItem(text, className) {
  const li = document.createElement("li");
  li.textContent = text;
  li.className = className;
  return li;
}
```
