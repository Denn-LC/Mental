# mental v1.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace v1.2's name-only players with Sign in with Google (guest play kept), with server-side sessions that are ready for the public web.

**Architecture:** A new `mental/web/auth.py` does Google's authorization code flow with PKCE using only the standard library. `mental/store.py` moves to schema version 2: Google-linked players with a chosen display name, hashed session tokens, and one-time OAuth states. The schema upgrade backs up and clears v1.2 data. `app.py` takes the player from the session cookie everywhere. The page gets a Welcome screen, guest mode, an Account screen and sign-in prompts.

**Tech Stack:** Python 3.14, uv, FastAPI, stdlib `sqlite3`/`urllib`/`secrets`/`hashlib`, pytest, vanilla HTML/CSS/JS. Browser check: Playwright via `uv run --with playwright` (not a project dependency).

**Spec:** `docs/superpowers/specs/2026-10-21-mental-v1.3-design.md` (builds on the v1, v1.1 and v1.2 specs)

## Global Constraints

- Runtime deps stay `fastapi`, `uvicorn`; dev deps stay `pytest`, `httpx2`. No new dependency: OAuth uses `urllib`, `secrets`, `hashlib`, `base64`.
- `src/mental/engine/` never imports FastAPI, `mental.web` or `mental.store`.
- Every SQL statement is a fixed string with `?` placeholders; values are passed separately. No f-string, `%`, `.format` or `+` builds SQL.
- Anything a person typed (a display name) goes on the page with `textContent`, never `innerHTML`.
- Display names: `^[A-Za-z0-9_.-]([A-Za-z0-9 _.-]{0,14}[A-Za-z0-9_.-])?$`, unique ignoring case. Same regex on both sides.
- Google scope is `openid` only. The app never asks for name, email or picture.
- Session cookie: `HttpOnly`, `SameSite=Lax`, `Path=/`, 30 days. On an `https` base url it is also `Secure` and named with the `__Host-` prefix. The database stores only the token's SHA-256 hex.
- The browser never names the player: no `player_id` in any request.
- Settings come only from environment variables: `MENTAL_BASE_URL` (default `http://127.0.0.1:8000`), `MENTAL_GOOGLE_CLIENT_ID`, `MENTAL_GOOGLE_CLIENT_SECRET`, `MENTAL_DB`. Nothing secret goes in the repo.
- Tests and the browser check never touch the real database or the real Google.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Coming back from Google in odd states.** A cancelled sign-in, a reused or expired `state`, a `state` that doesn't match this browser's cookie, or a code Google refuses. Each must land on Welcome with a message, with no session and no half-made player. → Task 3 callback tests.
2. **A stale or unknown session cookie.** Expired, signed out, made up, or from a database that was reset. The person must simply be a guest, never get an error page. → Task 2 `test_ended_expired_and_unknown_sessions_find_nobody`, Task 3 `test_signing_out`, Task 4 browser check "an unknown session cookie shows Welcome".
3. **Signed in but no display name yet.** Rounds are not saved, and leaving the name screen signs you out. Nothing half-saved is left. → Task 3 `test_a_round_before_choosing_a_name_is_not_saved`, Task 4 browser check "Esc on the first name screen signs out".
4. **Upgrading a real v1.2 database.** A backup must exist before anything is dropped. A second connection opening during the upgrade must not drop the new tables. → Task 2 `test_upgrading_a_v1_database_backs_it_up_and_clears_old_players`. Implementation: re-check the version inside `BEGIN IMMEDIATE`.
5. **Sign-in not configured.** The app must still work guest-only, with "sign-in isn't set up here" in place of the button. → Task 3 `test_sign_in_when_not_set_up` covers the API. """A stand-in for Google's token endpoint, so sign-in is tested without a network or an account."""
```python
import base64
import json
import time
import urllib.error


def b64json(data):
    return base64.urlsafe_b64encode(json.dumps(data).encode()).rstrip(b"=").decode()


def id_token(**claims):
    """An ID token shaped like Google's: header.payload.signature (the app never checks the signature)."""
    return f"{b64json({'alg': 'RS256'})}.{b64json(claims)}.signature"


def good_claims(sub, client_id="test-client"):
    return {"iss": "https://accounts.google.com", "aud": client_id, "exp": time.time() + 600, "sub": sub}


class FakeGoogle:
    """Replaces auth.post_form. A code put in `codes` is traded once for an ID token with its claims."""

    def __init__(self):
        self.codes = {}
        self.posts = []

    def __call__(self, url, fields):
        self.posts.append((url, fields))
        if fields.get("code") not in self.codes:
            raise urllib.error.HTTPError(url, 400, "invalid_grant", None, None)
        return {"id_token": id_token(**self.codes.pop(fields["code"]))}
```

```python
"""Sign in with Google: the OAuth 2.0 authorization code flow with PKCE, standard library only.

The browser goes to Google, Google sends it back with a one-time code, and the server trades that
code (with the PKCE verifier and the client secret) for an ID token directly with Google over
HTTPS. A token received that way needs no signature check (OpenID Connect Core 3.1.3.7), but its
claims are checked: issuer, audience, expiry and subject. Only the `openid` scope is asked for, so
Google tells us nothing but a stable account id (`sub`).
"""
import base64
import hashlib
import json
import os
import secrets
import time
import urllib.parse
import urllib.request
from dataclasses import dataclass

AUTH_URL = "https://accounts.google.com/o/oauth2/v2/auth"
TOKEN_URL = "https://oauth2.googleapis.com/token"
ISSUERS = ("https://accounts.google.com", "accounts.google.com")


class SignInFailed(Exception):
    pass


@dataclass(frozen=True)
class Settings:
    base_url: str
    client_id: str | None
    client_secret: str | None

    @property
    def enabled(self):
        return bool(self.client_id and self.client_secret)

    @property
    def secure(self):
        return self.base_url.startswith("https://")

    @property
    def redirect_uri(self):
        return f"{self.base_url}/auth/callback"


def settings():
    """Read from the environment each time, so tests and hosting can set it."""
    return Settings(
        base_url=os.environ.get("MENTAL_BASE_URL", "http://127.0.0.1:8000").rstrip("/"),
        client_id=os.environ.get("MENTAL_GOOGLE_CLIENT_ID") or None,
        client_secret=os.environ.get("MENTAL_GOOGLE_CLIENT_SECRET") or None,
    )


def new_state():
    return secrets.token_urlsafe(32)


def new_verifier():
    return secrets.token_urlsafe(64)  # 86 characters; PKCE allows 43-128


def sign_in_url(settings, state, verifier):
    challenge = base64.urlsafe_b64encode(hashlib.sha256(verifier.encode()).digest()).rstrip(b"=").decode()
    return AUTH_URL + "?" + urllib.parse.urlencode({
        "client_id": settings.client_id,
        "redirect_uri": settings.redirect_uri,
        "response_type": "code",
        "scope": "openid",
        "state": state,
        "code_challenge": challenge,
        "code_challenge_method": "S256",
        "prompt": "select_account",
    })


def post_form(url, fields):
    """POST a form over HTTPS (certificates checked by default) and return the JSON reply."""
    request = urllib.request.Request(url, data=urllib.parse.urlencode(fields).encode(), method="POST")
    with urllib.request.urlopen(request, timeout=10) as response:
        return json.load(response)


def google_account(settings, code, verifier):
    """Trade the one-time code for the Google account id (`sub`). SignInFailed if anything is off."""
    try:
        reply = post_form(TOKEN_URL, {
            "code": code,
            "client_id": settings.client_id,
            "client_secret": settings.client_secret,
            "redirect_uri": settings.redirect_uri,
            "grant_type": "authorization_code",
            "code_verifier": verifier,
        })
        payload = reply["id_token"].split(".")[1]
        claims = json.loads(base64.urlsafe_b64decode(payload + "=" * (-len(payload) % 4)))
    except (OSError, ValueError, LookupError, TypeError, AttributeError) as error:
        raise SignInFailed(f"unusable reply from Google ({error!r})") from None
    if not isinstance(claims, dict):
        raise SignInFailed("unusable reply from Google")
    if claims.get("iss") not in ISSUERS:
        raise SignInFailed("not issued by Google")
    if claims.get("aud") != settings.client_id:
        raise SignInFailed("issued for another app")
    expires = claims.get("exp")
    if isinstance(expires, bool) or not isinstance(expires, (int, float)) or expires <= time.time():
        raise SignInFailed("expired")
    sub = claims.get("sub")
    if not isinstance(sub, str) or not 0 < len(sub) <= 255:
        raise SignInFailed("no account id")
    return sub
```

(`OSError` covers network errors and Google's HTTP errors; `LookupError` covers a missing token or part; `ValueError` covers bad base64 and bad JSON.)

```python
def connect(path=None):
    path = Path(path or db_path())
    path.parent.mkdir(parents=True, exist_ok=True)
    # FastAPI may open the connection on one worker thread and use it on another (never at once)
    conn = sqlite3.connect(path, check_same_thread=False)
    conn.row_factory = sqlite3.Row
    try:
        conn.execute("PRAGMA foreign_keys = ON")
        if conn.execute("PRAGMA user_version").fetchone()[0] != SCHEMA_VERSION:
            upgrade(conn, path)
    except BaseException:
        conn.close()
        raise
    return conn


def upgrade(conn, path):
    """Bring the file to SCHEMA_VERSION. A version 1 file is backed up first, then cleared."""
    if conn.execute("PRAGMA user_version").fetchone()[0] == 1:
        backup = sqlite3.connect(path.with_name(path.name + ".v1-backup"))
        try:
            conn.backup(backup)
        finally:
            backup.close()
    conn.execute("BEGIN IMMEDIATE")  # one connection upgrades at a time
    try:
        version = conn.execute("PRAGMA user_version").fetchone()[0]  # another may have done it meanwhile
        if version > SCHEMA_VERSION:
            raise RuntimeError(f"{path} was made by a newer version of mental (schema {version})")
        if version == 1:
            for statement in DROP_V1:
                conn.execute(statement)
        if version < SCHEMA_VERSION:
            for statement in SCHEMA:
                conn.execute(statement)
        conn.commit()
    except BaseException:
        conn.rollback()
        raise
```

```python
    best = None
```

- [ ] **Step 9: Write `docs/google-sign-in.md`**

```markdown
# Setting up Sign in with Google

mental signs people in with Google's standard OAuth flow. It needs a Google OAuth client, which you
make once in Google Cloud Console. Without one the app still runs, guest-only.

## 1. Make the client

1. Open https://console.cloud.google.com and create a project (e.g. "mental").
2. **APIs & Services → OAuth consent screen**: choose **External**, give an app name and your
   email. No extra scopes are needed: mental asks only for `openid`. While the app is in
   **Testing**, add your own Google account under **Test users**. Only test users can sign in
   until you publish the app.
3. **APIs & Services → Credentials → Create credentials → OAuth client ID**, type
   **Web application**. Under **Authorized redirect URIs** add exactly:
   - `http://127.0.0.1:8000/auth/callback` (running on your machine)
   - later, `https://<your domain>/auth/callback` (when it goes online)
4. Copy the **Client ID** and **Client secret**.

## 2. Give them to mental

mental reads them from environment variables, so nothing secret is in the repo:

    export MENTAL_GOOGLE_CLIENT_ID=<client id>
    export MENTAL_GOOGLE_CLIENT_SECRET=<client secret>
    uv run mental

Put the two `export` lines somewhere outside the repo (e.g. your shell profile) and never commit them.
Open the app at **http://127.0.0.1:8000** (not `localhost`): Google only sends people back to the
exact address registered above.

## 3. When it goes online

Set `MENTAL_BASE_URL=https://<your domain>` on the server as well as the two variables above, and
make sure that domain's redirect address is in the client's list. On `https`, mental's cookies
become `Secure` and host-only automatically.
```
